# 项目文档索引

本文件是文档路由。先读 quick context，再按任务选择最小文档集。

## Source Of Truth

| 事实类型 | Owner |
| --- | --- |
| 项目身份和入口 | `docs/current/AGENT-QUICK-CONTEXT.md` |
| 当前状态 | `docs/current/STATUS.md` |
| 下一步 | `docs/plans/NEXT-STEPS.md` |
| 完成记录 | `docs/history/development-log.md` |
| 外部参考 | `docs/reference/INDEX.md` |

## 读取顺序

1. `docs/current/AGENT-QUICK-CONTEXT.md`
2. `docs/current/STATUS.md`
3. `docs/plans/NEXT-STEPS.md`
4. 按任务读取 active plan、reference 或 history

## 维护规则

- current docs 只写当前真相，不堆历史。
- history 写完成证据，不作为当前入口。
- docs 与 `.tscn`、`.gd`、`.tres` 冲突时，以当前文件为准并同步 docs。
